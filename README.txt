ЗАПУСК ЧЕРЕЗ GITHUB PAGES

1. Создайте новый публичный репозиторий GitHub, например strategy-session.
2. Загрузите в корень репозитория файл index.html из этой папки.
3. GitHub: Settings -> Pages.
4. Source / Build and deployment: Deploy from a branch.
5. Branch: main, Folder: / (root), Save.
6. Откройте выданную GitHub Pages ссылку вида:
   https://USERNAME.github.io/strategy-session/

Важно:
- Не проверяйте EasyRetro двойным кликом по локальному index.html (file://).
- Проверяйте именно по HTTPS-ссылке GitHub Pages.
- Для экранов после этапов 3-9 используется официальный iframe-код EasyRetro.
