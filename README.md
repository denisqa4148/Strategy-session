# Стратегическая веб-доска · ТРИ ЦЕНЫ

Совместная Streamlit-доска для 8 участников **без SQL, Supabase и внешней базы данных**.

## Как работает

Все участники открывают одну ссылку Streamlit Cloud. Данные хранятся в общей памяти запущенного приложения, поэтому карточки, голоса и план видны всем участникам.

Чтобы увидеть действия коллег, когда вы сами ничего не нажимали, используйте кнопку **«↻ Синхронизировать»**.

### Важно

Память Streamlit Cloud не является постоянным хранилищем. Если приложение перезапустится или уйдет в сон, данные могут сброситься. Поэтому у ведущего есть:

- **«Скачать резервную копию»** — JSON со всей доской;
- **«Восстановить из JSON»** — полное восстановление доски;
- итоговая выгрузка протокола в CSV.

Для одной 2-часовой внутренней сессии на 8 человек это самый простой вариант без подключения БД.

## Что умеет

- Lobby для участников.
- Режим ведущего по PIN.
- 10 этапов сессии.
- Общие стикеры.
- Развитие идей коллег.
- Провокации.
- Кластеризация.
- Голосование — до 5 голосов на участника.
- TOP-8 / TOP-3.
- Итоговый план действий.
- CSV-протокол.
- JSON backup/restore.

## Развертывание

1. Создайте новый репозиторий GitHub.
2. Загрузите туда `app.py` и `requirements.txt`.
3. В Streamlit Cloud создайте приложение из репозитория.
4. Main file: `app.py`.
5. Запустите приложение.

**Никакие SQL, Supabase и API-ключи не нужны.**

## PIN ведущего

По умолчанию PIN:

```text
2026
```

Если хотите изменить его, в Streamlit Secrets можно добавить только:

```toml
ADMIN_PIN="ваш-пин"
```

Это необязательно.

## Презентация

На этапе 2 ведущий вставляет ссылку на презентацию прямо в приложении. Отдельно настраивать Secrets для нее не нужно.

## Перед сессией

Рекомендую:

1. За 10–15 минут открыть приложение ведущим, чтобы Streamlit Cloud не был в спящем режиме.
2. Войти с PIN ведущего.
3. Вставить ссылку на презентацию на этапе 2.
4. Дать ссылку участникам.
5. После важных этапов скачивать резервную копию JSON — например после этапов 4, 7 и 9.
