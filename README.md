# Стратегическая сессия · Трафик ТРИ ЦЕНЫ

Версия без SQL, Supabase и внешней базы данных.

## Что улучшено

- светлый корпоративный интерфейс в стиле макета доски;
- автоматическая синхронизация экрана примерно раз в 6 секунд;
- таймер каждого этапа;
- единый маршрут из 10 этапов;
- этап 2 содержит только ссылку на презентацию — презентация транслируется отдельно;
- причины из этапа 1 используются на этапе 3 и раскладываются ведущим по зонам;
- развитие чужих идей показывает связь с исходной карточкой;
- провокации открываются ведущим по одной;
- кластеризация, 5 голосов на участника, TOP-8 и TOP-3;
- финальный план и CSV-протокол;
- backup / restore JSON для защиты от перезапуска Streamlit.

## Запуск на Streamlit Cloud

1. Создайте GitHub-репозиторий.
2. Загрузите в корень `app.py` и `requirements.txt`.
3. В Streamlit Cloud нажмите **New app** и выберите репозиторий.
4. Main file path: `app.py`.
5. Deploy.

База данных и SQL не требуются.

## PIN ведущего

По умолчанию: `2026`.

Чтобы заменить PIN, добавьте в Streamlit Cloud → App settings → Secrets:

```toml
ADMIN_PIN = "ваш-пин"
```

## Важно

Данные хранятся в памяти запущенного процесса Streamlit. Все участники одного экземпляра приложения видят общую доску, но при полном перезапуске / засыпании процесса данные могут потеряться. Перед началом и по ходу сессии ведущему рекомендуется скачивать JSON backup через панель ведущего.
